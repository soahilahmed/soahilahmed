## 👨‍💻 About Me

Hi, I'm **Sohail Ahmed**, a **Software Engineering student** with a strong passion for **Artificial Intelligence, Machine Learning, Deep Learning, Mobile App Development, and Software Engineering**. I enjoy building intelligent applications and solving real-world problems through technology.

My experience includes developing practical AI and Machine Learning projects using **Python**, **PyTorch**, **TensorFlow**, **Keras**, **Scikit-learn**, **Pandas**, **NumPy**, **OpenCV**, **Matplotlib**, and **Transformers**. I have worked with various deep learning architectures, including **Artificial Neural Networks (ANN)**, **Convolutional Neural Networks (CNN)**, **Recurrent Neural Networks (RNN)**, **Long Short-Term Memory (LSTM)**, and modern **Transformer-based models** for computer vision and natural language processing.

Alongside AI, I have experience in **Mobile Application Development** using **Flutter** and **Dart**, and I have also worked with **C, C++, C#, .NET**, Java, and modern software development practices. I continuously improve my skills by building projects, exploring new technologies, and contributing to open-source software.
